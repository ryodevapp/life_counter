# LifeCounter デザインシステム

- 決めた日: 2026-10-15(同日夜、iOS 26 の Liquid Glass と Material 3 Expressive を調べ直して改訂)
- 比は背景 #FDFBF7 に対する値(WCAG の式で計算)
- 根拠: Apple Human Interface Guidelines(Typography・Accessibility・Buttons・Segmented controls・Sheets・Motion・Dark Mode)、WCAG 2.2(1.4.3 コントラスト)、W3C JLREQ(日本語の行間)、Primer・Material 3 のトークン設計
- コードの正本: `lib/views/shared/`(`app_colors.dart`・`app_text_styles.dart`・`app_spacing.dart` と部品)。画面のコードに値を直接書かない

## 1. 考え方

- **やさしく、静か**。飾りより余白。ひとつの画面で目立たせるのは1つ
- **読めること**を先に。文字はコントラスト比 4.5:1 以上(18pt 以上と太字は 3:1 以上)
- **同じものは同じ形**。ボタン・カード・入力欄・切り替え・確認の小窓は、共通の部品だけを使う
- ガラス(Liquid Glass 風)は、内容の上に浮かぶ操作の部品(下のタブバー)だけ

## 3. 文字

文は**端末の書体**(英数字は SF、日本語はヒラギノ角ゴ。Apple の純正アプリと同じ)。大きな数字だけ Cormorant Garamond。日本語の字形がずれないよう `fontFamilyFallback` にヒラギノを指定する。絵文字は `Apple Color Emoji` を指定する(☀ などが黒い記号にならないように)。

| 名前 | 大きさ / 太さ / 行の高さ | 使い道 |
|---|---|---|
| `counter` | 76 / 300 / 1.0(数字) | 今日の「人生◯日目」だけ |
| `display` | 34 / 400 / 1.1(数字) | 大きな数字(人生タブなど) |
| `largeTitle` | 28 / 600 / 1.25 | 画面のいちばん上の題(ヒラギノは SF より黒く見えるので 34・太字にしない) |
| `title` | 22 / 700 / 1.35 | 詳しい画面の題・まとまりの題 |
| `headline` | 17 / 600 / 1.5 | カードの題・問いの文 |
| `body` | 17 / 400 / 1.6 | 本文・答え |
| `callout` | 15 / 400 / 1.6 | 一覧の本文・説明 |
| `footnote` | 13 / 400 / 1.5(textMuted) | 日付・補足 |
| `captionLabel` | 13 / 600 / 1.4(textMuted) | 小さい見出し(「今日の問い」など)・ラベル |
| `tab` | 11 / 600 / 1.2 | 下のタブの文字だけ |

- 最小は 11pt。それより小さい文字は使わない
- 字間は 0。英字の小見出しは使わない(画面の題は日本語)

## 7. 動き

- 位置と大きさは**ばね**で動かす(`AppMotion.spring` = 硬さ 380・減衰比 0.78。少しだけ弾む)。色と透明度は時間で(150〜220ms、弾ませない)
- 選んだ印(下のタブ・上の切り替え)は `SlidingPillTrack`。ばねで移り、動く間は進む向きに伸びる。指でなぞっても選べ、なぞる間は少し浮く。選んだときに軽い触覚
- シート 350ms。`Curves.easeOutCubic`
- 「視差効果を減らす」がオンのときは、すべる・広がる動きをやめる
- 色の切り替えは、同じ色の透明度 0 との間で動かす(`Colors.transparent` との間で動かすと、途中で灰色になる)

## 8. 部品

| 部品 | 決まり |
|---|---|
| ボタン | 主(accent の塗り・白い文字)・副(bgWarm の塗り)・文字だけ、の3種。高さ 50、カプセル。主ボタンは1画面に1つ |
| 下のタブ | 浮かぶガラスのカプセル(左右・下から 21pt、高さ 62)。アイコンは SF Symbols 風(CupertinoIcons)24pt、選ぶと塗りのアイコン。選んだ印は `SlidingPillTrack` |
| アイコン | すべて CupertinoIcons(Material のアイコンや記号の文字は使わない) |
| 1行で足す欄 | カプセルの欄の中、右端に丸いボタン(メッセージの送る印と同じ置き方)。書いていないときは押せない色 |
| 押せる範囲 | 44×44 以上(見た目が小さくても、押せる範囲は広げる) |
| カード | `AppCard`。角 20、内側 20、影 1。**押せる一件か、ひとまとまりの一覧にだけ使う**。説明文・空のときの案内・入力欄はカードに入れない。カードの中に塗りの欄を入れ子にしない |
| 切り替え | `AppSegmentedControl`。カプセルの土台(高さ 36、押せる範囲 44)、横幅いっぱい、項目は均等の幅、白いカプセルがばねですべる |
| 入力欄 | `AppInput`。角 md、bgWarm の塗り、高さ 48 以上 |
| リストの行 | 高さ 44 以上(設定の行は 52)、区切りは divider の 1px で、文字の頭から引く |
| 消す確認 | `showDeleteConfirmation` だけを使う。「消す」は danger の色、既定の選択にしない |
| お知らせ | `AppToast` だけを使う(SnackBar を直接書かない) |
| 空の状態 | 説明1文(callout・textMuted)。必要なら主ボタン1つ。絵文字は使わない |
| 画面の題 | `PageHeader`。日本語の題(largeTitle 34pt 太字)を左寄せ |

## 9. 言葉

- 操作の言葉は iOS の決まった言い方にそろえる: 追加・編集・削除・完了・キャンセル(「足す」「消す」は使わない)
- バケットリストは「バケットリスト」と呼ぶ(「やりたいこと」と言い換えない)。かなえたものは「かなえた」(「できた」「達成」は使わない)。かなえたものも消さず、取り消し線も引かない
- 日付は「2026年10月15日」「10月15日（木）」。かっこは全角「（）」。オン/オフはカタカナ
- 罪悪感をあおる促し(「そろそろ会いたくなりませんか？」)と、説教の文(「かけがえのない時間です」)を書かない

- 「余命」「寿命」「死ぬまで」「あと何日」を画面に出さない。平均の値を使うときは「平均までの目安」「これからの目安」と書く
- 利用者に命令しない(「〜しましょう」「〜してください」を使わない)。できることを書く(「〜できます」)
